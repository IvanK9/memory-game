## Игра Найди пару

Это игра на развитие памяти и внимания, в которой нужно открывать парные карточки

## Возможности

- Поле 4×4 с 16 карточками, колода перемешивается в начале каждой игры.
- Клик открывает карточку; клик по второй карточке завершает ход.
- Совпавшая пара остаётся открытой, несовпавшие закрываются через 1 с.
- Счётчики: число ходов и найденных пар.
- При 8 найденных парах появляется модальное окно победы с итоговым числом ходов.
- Кнопка «Новая игра» пересобирает поле с новой перемешанной колодой.
- Кнопка "Таблица лидеров" открывает таблицу с 10 лучшими результатоми.

## Технологии

- Чистый HTML, CSS и JavaScript (ES6+), без библиотек и сборщиков.

## Локальный запуск

1. Склонируйте репозиторий и перейдите в ветку `memory-game`:
   ```bash
   git clone <адрес-репозитория>
   cd <папка-репозитория>
   git checkout memory-game
   ```
2. Откройте index.html и запустите live server (если вы используете VSC).
3. Либо используйте ссылку на gh-pages
